# LLM Studio 插件开发指南

## 概述

LLM Studio 插件系统允许开发者扩展应用的功能。插件可以是：

1. **工具技能** - 执行特定任务（如网络爬取、数据分析）
2. **专家技能** - 提供专业领域知识（如法律咨询、医疗建议）
3. **集成技能** - 与外部服务集成（如 API 调用、数据库操作）

## 开发步骤

### 1. 创建插件项目结构

```
my-plugin/
├── plugin.json           # 插件清单
├── lib/
│   └── main.dart        # 插件入口
├── assets/
│   └── icon.png         # 插件图标
└── README.md            # 插件说明
```

```json
    "timeout": 30000
  }

```

### 3. 实现插件逻辑

#### Dart 插件示例

```dart
// lib/main.dart
import 'dart:async';
import 'dart:convert';
import 'package:http/http.dart' as http;

/// 插件入口函数
Future<Map<String, dynamic>> execute(Map<String, dynamic> params) async {
  final input = params['input'] as String;
  final maxLength = params['max_length'] as int? ?? 100;
  
  // 执行插件逻辑
  final result = await processData(input, maxLength);
  
  return {
    'success': true,
    'data': result,
    'timestamp': DateTime.now().toIso8601String(),
  };
}

/// 处理数据
Future<String> processData(String input, int maxLength) async {
  // 示例：调用外部 API
  final response = await http.post(
    Uri.parse('https://api.example.com/process'),
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({'text': input}),
  );
  
  if (response.statusCode == 200) {
    final data = jsonDecode(response.body);
    final result = data['result'] as String;
    return result.length > maxLength 
        ? result.substring(0, maxLength) 
        : result;
  } else {
    throw Exception('API request failed: ${response.statusCode}');
  }
}
```

#### 脚本插件示例

```python
#!/usr/bin/env python3
# script.py
import sys
import json

def main():
    # 从标准输入读取参数
    params = json.loads(sys.stdin.read())
    input_text = params.get('input', '')
    max_length = params.get('max_length', 100)
    
    # 处理逻辑
    result = input_text.upper()[:max_length]
    
    # 输出结果
    print(json.dumps({
        'success': True,
        'data': result,
    }))

if __name__ == '__main__':
    main()
```

## 最佳实践

### 1. 错误处理

```dart
Future<Map<String, dynamic>> execute(Map<String, dynamic> params) async {
  try {
    // 验证参数
    if (params['input'] == null) {
      return {
        'success': false,
        'error': 'Missing required parameter: input',
      };
    }
    
    // 执行逻辑
    final result = await doSomething(params['input']);
    
    return {
      'success': true,
      'data': result,
    };
  } catch (e) {
    return {
      'success': false,
      'error': e.toString(),
    };
  }
}
```

### 2. 超时处理

```dart
Future<Map<String, dynamic>> execute(Map<String, dynamic> params) async {
  final timeout = Duration(milliseconds: params['timeout'] ?? 30000);
  
  try {
    final result = await Future.any([
      doLongRunningTask(),
      Future.delayed(timeout, () => throw TimeoutException('Task timed out')),
    ]);
    
    return {'success': true, 'data': result};
  } on TimeoutException catch (e) {
    return {'success': false, 'error': 'Timeout: $e'};
  }
}
```

### 3. 日志记录

```dart
Future<Map<String, dynamic>> execute(Map<String, dynamic> params) async {
  print('[MyPlugin] Starting execution with params: $params');
  
  try {
    final result = await doSomething();
    print('[MyPlugin] Execution completed successfully');
    return {'success': true, 'data': result};
  } catch (e) {
    print('[MyPlugin] Execution failed: $e');
    return {'success': false, 'error': e.toString()};
  }
}
```

### 4. 资源清理

```dart
class MyPlugin {
  http.Client? _client;
  
  Future<Map<String, dynamic>> execute(Map<String, dynamic> params) async {
    _client = http.Client();
    
    try {
      final result = await _client!.get(Uri.parse('https://example.com'));
      return {'success': true, 'data': result.body};
    } finally {
      _client?.close();
    }
  }
}
```


## 常见问题

### Q: 插件如何访问 LLM Studio 的数据？

A: 目前插件只能通过参数接收数据，不能直接访问应用内部数据。未来版本可能会添加更多集成点。

### Q: 插件可以使用第三方库吗？

A: Dart 插件可以使用 pub.dev 上的库，但需要在 plugin.json 中声明依赖。脚本插件需要确保运行环境已安装所需依赖。

### Q: 插件有大小限制吗？

A: 建议插件包大小不超过 10MB，以确保快速下载和安装。

### Q: 如何调试插件？

A: 可以在插件代码中使用 `print()` 输出调试信息，这些信息会显示在应用日志中。
