## 任务1: 会话列表首页自动刷新

### 问题描述
用户进入会话列表页面时，数据不会自动刷新，需要手动操作才能看到最新会话。

### 修复方案
- **文件**: `multi_model_client/lib/features/session/presentation/pages/session_list_page.dart`
- **机制**: 利用 `didChangeDependencies` 生命周期钩子，在页面每次显示时自动触发刷新
- **优化**: 添加 100ms 延迟，确保数据库写入完成后再刷新

### 关键代码
```dart
@override
void didChangeDependencies() {
  super.didChangeDependencies();
  WidgetsBinding.instance.addPostFrameCallback((_) {
    if (mounted) {
      Future.delayed(const Duration(milliseconds: 100), () {
        if (mounted) _refreshSessionList();
      });
    }
  });
}
```

## 任务2: AI响应与TTS稳定性修复

### 问题描述
1. AI会出现重复响应（同一条消息被发送多次）
2. TTS语音播报不稳定（切换消息时丢失TTS引擎绑定）

### 修复方案

#### 2.1 防止重复AI响应
- **文件**: `multi_model_client/lib/features/session/presentation/pages/session_detail_page.dart`
- **机制**: 添加 `_isSending` 布尔守卫标志
- **逻辑**: 
  - 发送开始时设置 `_isSending = true`
  - 所有提前返回路径和 finally 块中重置为 `false`
  - 并发调用时直接跳过

#### 2.2 TTS服务缓存
- **文件**: `multi_model_client/lib/features/session/presentation/pages/session_detail_page.dart`
- **机制**: 缓存 `TTSService` 实例，仅在设置变更时重建
- **逻辑**:
  - 使用 `_cachedTtsService` 缓存实例
  - 使用 `_ttsSettingsFingerprint` 记录设置指纹
  - 设置变更时才重建实例并调用 `warmUpSystemTts()`

### 关键代码

#### 防重复发送
```dart
bool _isSending = false;

Future<void> _sendMessage(String text) async {
  if (_isSending) {
    debugPrint('[SessionDetail] ⚠️ _sendMessage 正在执行中，跳过重复调用');
    return;
  }
  _isSending = true;
  
  try {
    // ... 发送逻辑
  } finally {
    _isSending = false;
  }
}
```

#### TTS缓存
```dart
TTSService? _cachedTtsService;
String _ttsSettingsFingerprint = '';

// 使用时检查指纹
final settingsFingerprint = '$ttsProvider|$ttsModelId|$ttsVoice|$ttsSpeed|$ttsApiKey';
if (_cachedTtsService == null || _ttsSettingsFingerprint != settingsFingerprint) {
  _cachedTtsService = TTSService(...);
  _ttsSettingsFingerprint = settingsFingerprint;
  await _cachedTtsService!.warmUpSystemTts();
}
```

## 任务3: 语音输入交互优化（微信风格）

### 问题描述
语音输入体验不佳，缺乏实时反馈，用户不知道当前识别状态。

### 修复方案

#### 3.1 ASR服务增强
- **文件**: `multi_model_client/lib/core/services/asr_input_service.dart`
- **新增**: `_intermediateTextController` (StreamController<String>.broadcast())
- **新增**: `intermediateTextStream` getter
- **新增**: `_lastSystemAsrText` 字段跟踪最新识别文本
- **重构**: `_startSystemAsr()` 方法，中间结果实时推送，最终结果在 `onDone` 时推送

#### 3.2 语音浮动气泡
- **文件**: `multi_model_client/lib/features/session/presentation/pages/session_detail_page.dart`
- **新增**: `_voiceBubbleText` 状态变量
- **新增**: `_voiceIntermediateSub` 订阅
- **新增**: `_buildVoiceFloatingBubble()` widget
- **交互**: 按住录音时显示浮动气泡，实时显示识别文本

### 关键代码

#### ASR中间结果流
```dart
// 新增字段
final StreamController<String> _intermediateTextController =
    StreamController<String>.broadcast();
Stream<String> get intermediateTextStream => _intermediateTextController.stream;

String _lastSystemAsrText = '';

// _startSystemAsr() 中
_lastSystemAsrText = '';
final stream = _asrService.recognizeWithSystem(
  onResult: (text) {
    if (text.trim().isNotEmpty) {
      _lastSystemAsrText = text.trim();
      _intermediateTextController.add(text.trim()); // 实时 → 气泡
    }
  },
  onDone: () {
    _isSystemAsrRunning = false;
    if (_lastSystemAsrText.isNotEmpty) {
      _resultController.add(_lastSystemAsrText); // 最终 → 输入框
    }
  },
);
```

#### 浮动气泡widget

## 任务4: 性能优化

### 问题描述
1. 消息列表滚动卡顿
2. TTS服务频繁重建导致性能损耗

### 修复方案

#### 4.1 RepaintBoundary优化
- **文件**: `multi_model_client/lib/features/session/presentation/pages/session_detail_page.dart`
- **机制**: 为每个消息气泡添加 `RepaintBoundary` 包装
- **效果**: 隔离重绘区域，避免单个消息更新导致整个列表重绘

#### 4.2 TTS实例缓存
- 详见任务2.2的TTS缓存方案

### 关键代码
```dart
// 消息列表中的RepaintBoundary

// 流式消息
```

## 技术要点

1. **Flutter生命周期**: `didChangeDependencies` 在路由切换时触发
2. **StreamController.broadcast()**: 支持多个监听器的广播流
3. **RepaintBoundary**: 性能优化，隔离重绘区域
4. **SafeArea**: 自动处理系统UI遮挡
5. **指纹比对**: 通过字符串指纹判断设置是否变更
