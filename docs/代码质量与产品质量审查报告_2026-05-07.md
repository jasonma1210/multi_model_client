```
lib/

│   ├── storage/             # 数据库（Drift ORM）
│   ├── theme/               # 主题系统
│   ├── utils/               # 工具类
│   └── widgets/             # 共享组件
├── features/                (52 文件, 33,722 行)
│   ├── av/                  # 音视频交互

│   ├── model/               # 模型管理
│   ├── prompt/              # 提示词管理

│   ├── session/             # 会话管理
│   ├── settings/            # 设置
│   ├── skill/               # Skills 插件系统
│   └── summary/             # 智能总结
└── generated/               (3 文件, 5,914 行)
```

**架构评价**：
- ✅ **分层清晰**：core（基础设施）/ features（业务逻辑）/ generated（自动生成）正确分离
- ✅ **状态管理**：Riverpod StateNotifier 模式一致
- ✅ **路由**：go_router 嵌套路由，支持 back 手势返回
- ✅ **数据库**：Drift ORM 类型安全，14 张表
- ⚠️ **超大文件**：52 个文件超 500 行（占 33%），session_detail_page.dart 达 5,096 行（待后续拆分）
