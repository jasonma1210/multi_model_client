# MJ Nexus v0.44.0 实施计划

> 版本：v0.44.0 | 状态：**全部完成** | 日期：2026-06-30

## 概述

v0.44.0 聚焦于 Function Calling 真实接入、性能优化、模型加载策略优化和跨平台编译验证，共完成 4 个核心任务。

## Task 1: LLM Function Calling 真实接入（Stage A）

### A3.5: 本地 FFI 真 FC ✅
- 新建 `lib/core/engines/fc_patterns.dart`
  - 4 种 FC 模板正则（Qwen/Hermes/Llama 3.1/Mistral）+ 通用兜底
  - `FcPromptTemplates` 注入工具描述到 System Prompt
  - `FcOutputParser` 解析流式输出中的工具调用
- 修改 `lib/core/engines/local_ffi_engine.dart`
  - 新增 `generateStreamWithTools` 方法（不改原 `generateStream` 签名）
  - 新增 `_injectToolPrompt` 方法

### A3.4: DialogueEngine 编排 ✅
- 修改 `lib/features/session/domain/dialogue_engine.dart`
  - `streamResponse` 改用 `generateChatStreamWithTools`
  - 获取 MCP 工具 → 构建 FC tools → 注入 ChatOptions
  - 检测 `chunk.toolCall` → 追踪 `detectedToolCall`
  - 新增 `_executeRealToolCall` 方法（执行工具 → 通知 UI → 回填数据库）
  - 保留伪 FC 作为兜底（`_checkAndExecuteMcpTools`）

## Task 2: B1-B6 性能优化 ✅

### B1: 图片处理进 Isolate
- `lib/core/multimodal/services/image_preprocess_service.dart`
- 新增顶层函数 `_processBytesInIsolate`（compute 要求）
- `processBytes` 改用 `await compute()`，保留 `_processBytesSync` fallback

### B2: MessageParser 结果缓存
- `lib/features/session/presentation/widgets/message_bubble.dart`
- `_AssistantBubbleState` 新增静态 LRU 缓存（容量 50）
- 新增 `_parseWithCache` 方法，避免每次 build 重复正则扫描

### B3: sessionStateProvider select 拆分
- 保留原 `ref.watch(sessionStateProvider)`（因 sessionState 的 error/activeSession/messages 多字段被使用，select 拆分需改方法签名，违反收敛性原则）

### B4: 振幅节流
- `lib/features/session/presentation/pages/session_detail_page.dart`
- 新增 `_lastAmplitudeUpdate` 字段
- 振幅 listen 回调中加 200ms 节流

### B5: 输入框 ValueListenableBuilder
- 发送按钮区域用 `ValueListenableBuilder<TextEditingValue>` 包裹
- 避免每次文字变化都 setState 重建整棵树

### B6: 会话切换显式 dispose
- `didUpdateWidget` 中会话切换时先清理定时器和订阅
- 新增 `_contextPollTimer`、`_voiceAmplitudeSub` 等的取消逻辑
- 重建上下文轮询定时器

## Task 3: C1-C3 模型加载策略优化 ✅

### C1: LocalFFIEngine LRU 缓存
- `lib/core/engines/local_ffi_engine.dart`
- 新增 `_CachedEngine` 类（含 LlamaEngine、ChatSession、modelPath 等）
- 新增 `_engineCache` 字段（Map，容量 2）
- `loadModel` 改造：先查缓存命中则复用，未命中将当前引擎存入缓存
- 新增 `_saveCurrentEngineToCache`、`clearCache` 方法
- `dispose()` 同时清理 LRU 缓存

### C2: 流式 StreamController 包装
- `lib/core/engines/model_inference_engine.dart`
- 新增 `generateChatStreamControlled` 方法（用 StreamController 包装）
- 新增 `_activeControllers` 字段
- `cancelGeneration` 同时关闭 StreamController

### C3: 错误恢复重试
- 新增 `_retryableGenerate` 方法（网络错误自动重试 3 次，指数退避 1s/2s/4s）
- 新增 `_isNetworkError`、`_isContextTooLongError` 检测方法
- 上下文超长错误不重试
