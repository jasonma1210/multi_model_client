## 产品简介

Multi-Model Client 是一款跨平台的智能对话助手，支持本地和云端大语言模型，具备以下核心特性：

### ✨ 核心功能

- **多模型支持**：本地gguf模型 + 云端API（OpenAI、Anthropic等）
- **会话隔离**：每个会话独立配置，互不干扰
- **智能记忆**：四层记忆架构，自动提取和召回关键信息
- **知识库RAG**：上传文档，构建专属知识库
- **MCP工具调用**：集成6个内置服务器，支持工具调用
- **跨平台同步**：macOS、iOS、Android、Windows多端支持

### 🎯 适用场景

- 💼 **个人助理**：日常对话、信息查询、文档总结
- 📚 **学习研究**：知识管理、文献阅读、笔记整理
- 💻 **开发辅助**：代码生成、调试帮助、技术问答
- 🎨 **创意工作**：内容创作、头脑风暴、方案设计

## 快速开始

### 第一步：安装应用

#### macOS用户

1. 从官网下载 `.dmg` 安装包
2. 双击打开，将应用拖入 Applications 文件夹
3. 首次启动时，右键点击应用 → 打开（解决安全验证问题）
4. 授予网络访问权限（系统会自动提示）

#### iOS用户

1. 从 App Store 下载安装
2. 首次启动，授予必要的网络权限

#### Android用户

1. 从官网下载 `.apk` 安装包
2. 允许安装未知来源应用
3. 完成安装

#### Windows用户

1. 从官网下载 `.exe` 安装包
2. 双击运行安装程序
3. 按提示完成安装

---

### 第二步：选择模型

应用支持两种模型使用方式：

#### 方式一：使用云端模型（推荐新手）

**优点：** 无需下载，即刻可用，性能稳定

**支持的API：**
- OpenAI (GPT-4, GPT-3.5)
- Anthropic (Claude系列)
- 其他兼容OpenAI格式的API

**配置步骤：**

1. 进入「设置」→「API管理」
2. 点击「添加API密钥」
3. 选择服务商，输入API Key
4. 保存配置

#### 方式二：使用本地模型（推荐进阶用户）

**优点：** 数据隐私，离线可用，无API费用

**支持的模型格式：**
- GGUF格式（推荐）
- 支持硬件加速：Metal (macOS/iOS)、CUDA (Windows)

**模型来源：**

1. **ModelScope（国内推荐）**
   - 访问：设置 → 模型管理 → ModelScope
   - 搜索模型，点击下载
   - 自动使用国内镜像，速度快

2. **HuggingFace**
   - 访问：设置 → 模型管理 → HuggingFace
   - 支持镜像自动切换
   - 推荐使用国内镜像

**推荐模型：**

| 模型名称 | 参数量 | 内存需求 | 适用场景 |
|---------|--------|----------|----------|
| Qwen-7B-Chat | 7B | ~5GB | 通用对话 |
| Llama-3-8B | 8B | ~6GB | 英文对话 |
| Yi-6B-Chat | 6B | ~4GB | 中英双语 |

**下载步骤：**

1. 进入「模型管理」页面
2. 选择「ModelScope」或「HuggingFace」
3. 搜索模型名称
4. 点击下载，等待完成
5. 下载完成后，模型自动出现在可用列表

---

### 第三步：创建第一个会话

1. 点击主界面左上角「+」按钮
2. 输入会话名称（如："日常助手"）
3. 选择模型：
   - 如果已配置API，选择云端模型
   - 如果已下载本地模型，选择本地模型
4. （可选）配置系统提示词：
   ```
   你是一个友好的AI助手，专注于帮助用户解决问题。
   ```
5. 点击「创建」，会话列表中出现新会话

---

### 第四步：开始对话

**基础对话：**

1. 点击会话进入对话界面
2. 在底部输入框输入问题
3. 点击发送，等待AI回复
4. 查看回复内容

**流式输出：**

- 应用默认启用流式输出
- 可以实时看到AI逐字生成回复
- 更自然的对话体验

**工具调用（MCP）：**

如果你的会话启用了MCP服务器，AI可以自动调用工具：

1. 在会话设置中启用MCP服务器
2. AI会在需要时自动调用工具
3. 例如：查询天气、搜索网页、执行计算等

### 记忆引擎

#### 四层记忆架构

1. **瞬时记忆**：当前对话上下文
2. **工作记忆**：近期重要信息（1小时内）
3. **短期记忆**：临时记录（1天内）
4. **长期记忆**：永久保存的重要信息

#### 自动提取

- AI自动从对话中提取关键信息
- 存储：实体、事实、偏好
- 跨会话记忆召回

#### 手动管理

- 访问：会话详情 → 记忆管理
- 查看、编辑、删除记忆
- 标记重要程度

步骤：

2. 点击「上传文档」

2. 对话时，自动检索相关知识
3. AI回复融入知识库内容

## 进阶功能

### MCP工具调用

#### 内置MCP服务器

应用提供6个内置服务器：

1. **文件系统服务器**
   - 文件读写操作
   - 目录管理

2. **网络搜索服务器**
   - 网页搜索
   - URL解析

3. **代码执行服务器**
   - Python代码执行
   - 安全沙箱环境

4. **数据库服务器**
   - SQLite数据库操作
   - 数据查询

5. **计算器服务器**
   - 数学计算
   - 单位转换

6. **日历服务器**
   - 日历事件管理
   - 提醒设置

#### 启用MCP

1. 会话设置 → MCP服务器
2. 勾选需要的服务器
3. AI自动在对话中调用

#### 工具调用示例

```
用户：帮我计算一下3的5次方
AI：[调用计算器工具]
结果：243
```

## 常见问题

### 网络问题

#### Q: HuggingFace无法访问？

**A:** 使用网络诊断工具

1. 进入「设置」→「网络诊断」
2. 点击「开始诊断」
3. 查看各平台连接状态
4. 根据建议修复

**解决方案：**
- 系统自动使用国内镜像（hf-mirror.com）
- ModelScope国内可直接访问
- 检查防火墙设置
- macOS用户：确保应用有网络权限

---

#### Q: ModelScope下载很慢？

**A:**

1. 检查网络连接
2. 尝试切换网络（WiFi/有线）
3. 使用代理（设置 → 网络 → 代理配置）
4. 避开高峰时段下载

---

### 模型问题

#### Q: 模型加载失败？

**A:**

可能原因：
1. **内存不足**
   - 7B模型需要~5GB内存
   - 13B模型需要~10GB内存
   - 关闭其他应用释放内存

2. **文件损坏**
   - 删除模型，重新下载
   - 检查下载完整性

3. **硬件不兼容**
   - 检查系统版本
   - 更新显卡驱动（Windows）

---

#### Q: 推理速度慢？

**A:**

优化方法：
1. **启用硬件加速**
   - macOS：确保使用Metal
   - Windows：安装CUDA驱动

2. **选择合适的量化级别**
   - Q4_K_M：推荐（平衡速度和质量）
   - Q5_K_S：高质量，稍慢
   - Q8_0：最高质量，最慢

3. **减少上下文长度**
   - 会话设置 → 高级设置
   - 降低max_context参数

---

### 功能问题

#### Q: 记忆不生效？

**A:**

检查以下设置：
1. 会话设置 → 启用「全局记忆」
2. 记忆管理 → 确认记忆已存储
3. 对话时提示AI使用记忆

---

#### Q: 知识库检索不准确？

**A:**

优化方法：
1. **文档质量**
   - 确保文档清晰、格式规范
   - 避免扫描图片PDF

2. **分段设置**
   - 知识库设置 → 分段大小
   - 调整为500-1000字符

3. **检索参数**
   - 相似度阈值：0.7-0.8
   - 返回文档数：3-5个

---

#### Q: MCP工具调用失败？

**A:**

排查步骤：
1. 确认MCP服务器已启用
2. 检查工具权限设置
3. 查看日志：设置 → 开发者选项 → 日志
4. 重启应用
