### 4. Language Provider Created

**File**: `lib/core/providers/locale_provider.dart`

```dart
/// Supported locales
const supportedLocales = [
  Locale('en', 'US'),
  Locale('zh', 'CN'),
];

/// Language provider with Riverpod
final localeProvider = StateNotifierProvider<LocaleNotifier, Locale>((ref) {
  return LocaleNotifier();
});

class LocaleNotifier extends StateNotifier<Locale> {
  LocaleNotifier() : super(const Locale('en', 'US')); // Default to English

  void setLocale(Locale locale) {
    state = locale;
  }

  void toggleLocale() {
    if (state.languageCode == 'en') {
      state = const Locale('zh', 'CN');
    } else {
      state = const Locale('en', 'US');
    }
  }
}
```

## 🎨 Implementation Pattern

### Usage in Widgets

```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../../../../l10n/app_localizations.dart';

class MyWidget extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final l10n = AppLocalizations.of(context)!;
    
    return Column(
      children: [
        Text(l10n.sessions),
        ElevatedButton(
          onPressed: () => _showDialog(context, l10n),
          child: Text(l10n.create),
        ),
      ],
    );
  }
  
  void _showDialog(BuildContext context, AppLocalizations l10n) {
    showDialog(
      context: context,
      builder: (context) => AlertDialog(
        title: Text(l10n.createSession),
        content: Text(l10n.sessionName),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context),
            child: Text(l10n.cancel),
          ),
          ElevatedButton(
            onPressed: () => Navigator.pop(context),
            child: Text(l10n.create),
          ),
        ],
      ),
    );
  }
}
```

void _showLanguageDialog(BuildContext context, WidgetRef ref, AppLocalizations l10n) {

              ref.read(localeProvider.notifier).setLocale(Locale('zh', 'CN'));

  );

## 🎯 How to Use

### 1. Switch Language Programmatically
```dart
// Get current locale
final currentLocale = ref.read(localeProvider);

// Switch to English
ref.read(localeProvider.notifier).setLocale(Locale('en', 'US'));

// Switch to Chinese
ref.read(localeProvider.notifier).setLocale(Locale('zh', 'CN'));

// Toggle between languages
ref.read(localeProvider.notifier).toggleLocale();
```

### 2. Use Translations in Widgets
```dart
final l10n = AppLocalizations.of(context)!;

Text(l10n.sessions)  // "Sessions" or "会话"
Text(l10n.create)     // "Create" or "创建"
```

### 3. Add New Translations
1. Add key to `lib/l10n/app_en.arb`:
```json
"newKey": "New Key",
"@newKey": {
  "description": "Description of the key"
}
```

2. Add translation to `lib/l10n/app_zh.arb`:
```json
"newKey": "新键"
```

3. Run code generation:
```bash
flutter gen-l10n
```

4. Use in code:
```dart
Text(l10n.newKey)
```
