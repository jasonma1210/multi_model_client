## 一、设计概述

### 1.1 设计目标

**核心目标**: 设计简洁、直观、高效的移动端UI,对标Cherry Studio桌面端体验,针对移动端场景优化交互流程。

**设计原则**:
1. **简洁至上**: 核心功能≤3步可达
2. **会话中心**: 以会话为核心交互单元
3. **流畅体验**: 动画流畅,响应快速
4. **一致性**: 设计系统统一,交互逻辑一致
5. **可访问性**: 支持深色模式、字体调节

### 1.2 设计规范

#### 色彩系统
```
主色 (Primary):
- Primary: #6366F1 (Indigo 500)
- Primary Dark: #4F46E5 (Indigo 600)
- Primary Light: #818CF8 (Indigo 400)

辅助色 (Secondary):
- Secondary: #EC4899 (Pink 500)
- Secondary Dark: #DB2777 (Pink 600)

中性色 (Neutral):
- Gray 50: #F9FAFB (背景)
- Gray 100: #F3F4F6 (分割线)
- Gray 200: #E5E7EB (边框)
- Gray 300: #D1D5DB (禁用)
- Gray 600: #4B5563 (次要文本)
- Gray 900: #111827 (主要文本)

功能色:
- Success: #10B981 (Green 500)
- Warning: #F59E0B (Amber 500)
- Error: #EF4444 (Red 500)
- Info: #3B82F6 (Blue 500)
```

#### 字体系统
```
字体族:
- iOS: SF Pro
- Android: Roboto

字号:
- Display Large: 32px (标题)
- Display Medium: 28px (副标题)
- Heading Large: 24px (卡片标题)
- Heading Medium: 20px (列表标题)
- Body Large: 16px (正文)
- Body Medium: 14px (次要文本)
- Body Small: 12px (辅助文本)
- Caption: 11px (标签)

行高:
- Tight: 1.2
- Normal: 1.5
- Relaxed: 1.75
```

#### 间距系统
```
间距倍数: 4px
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- 2xl: 48px
- 3xl: 64px
```

#### 圆角系统
```
- sm: 4px (按钮、标签)
- md: 8px (卡片)
- lg: 12px (对话框)
- xl: 16px (底部sheet)

```

## 六、交互设计规范

### 6.1 手势交互

| 手势 | 操作 |
|:---|:---|
| 左滑 | 显示删除/归档/置顶按钮 |
| 右滑 | 返回上一页 |
| 长按 | 显示操作菜单 |
| 双击 | 快速操作 (如点赞、收藏) |
| 捏合 | 缩放图片 |
| 下拉 | 刷新列表 |

### 6.2 动画规范

**页面转场动画**:
- 时长: 300ms
- 缓动: ease-out
- 方向: 从右向左滑入 (push) / 从左向右滑出 (pop)

**列表项动画**:
- 时长: 200ms
- 缓动: ease-in-out
- 效果: 淡入淡出 + 轻微位移

**按钮点击动画**:
- 时长: 100ms
- 缓动: ease-out
- 效果: 缩放 0.95

### 6.3 反馈机制

**加载状态**:
- 骨架屏 (Skeleton)
- 加载动画 (CircularProgressIndicator)
- 下拉刷新

**成功状态**:
- Toast提示 (2秒自动消失)
- SnackBar (可撤销操作)

**错误状态**:
- 错误对话框
- 错误页面 (EmptyState)

**空状态**:
- 空状态插图
- 引导操作文字
