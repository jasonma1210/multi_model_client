**代码改进**:
```dart
// model_inference_engine.dart
void cancelGeneration(String modelId) {
  // 取消同步生成
  final operation = _activeGenerations.remove(modelId);
  if (operation != null) {
    operation.cancel();
  }

  // 取消流式生成
  final subscription = _activeStreams.remove(modelId);
  if (subscription != null) {
    subscription.cancel();
  }
}
```

**功能特性**:
- 支持取消正在进行的生成任务
- 正确释放资源
- 防止内存泄漏
