## 二、需求分析

### 2.1 用户需求
1. **点击版本号**：自动检查一次更新
2. **有更新**：弹出是否要更新的提示窗
3. **不更新**：后面显示 "new" 红色提示
4. **再次点击**：可以再次弹窗是否要更新，直到版本一致后不弹窗

### 2.2 需要新增的状态

| 状态 | 存储方式 | 说明 |
|-----|---------|------|
| `lastCheckTime` | SharedPreferences | 上次检查时间 |
| `skippedVersion` | SharedPreferences | 用户拒绝更新的版本号 |
| `hasNewVersion` | 内存状态 | 当前是否有新版本 |

### 3.1 创建版本检查服务

```dart
// lib/core/services/app_update_service.dart
class AppUpdateService {
  static const String _keySkippedVersion = 'skipped_version';
  static const String _keyLastCheckTime = 'last_check_time';
  
  /// 检查应用更新（从 GitHub Releases API）
  Future<AppVersion?> checkForUpdate() async {
    final response = await Dio().get(
      'https://api.github.com/repos/Jianma-Android/LLM-Studio/releases/latest',
    );
    // 解析版本号
  }
  
  /// 标记用户跳过此版本
  Future<void> skipVersion(String version) async {
    await prefs.setString(_keySkippedVersion, version);
  }
  
  /// 清除跳过状态
  Future<void> clearSkippedVersion() async {
    await prefs.remove(_keySkippedVersion);
  }
  
  /// 检查是否需要显示 new 标签
  bool shouldShowNewBadge(String currentVersion, String? skippedVersion) {
    return skippedVersion != null && skippedVersion != currentVersion;
  }
}
```

### 3.2 修改 Settings Page UI

```dart
// settings_page.dart 修改

// 1. 点击版本号触发检查
_SettingsTile(
  icon: Icons.info_outline,
  title: l10n.version,
  subtitle: _appVersion,
  trailing: Row(
    mainAxisSize: MainAxisSize.min,
    children: [
      if (_hasNewVersion) // 有新版本且用户跳过
        Container(
          padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
          decoration: BoxDecoration(
            color: Colors.red,
            borderRadius: BorderRadius.circular(4),
          ),
          child: const Text('NEW', style: TextStyle(color: Colors.white, fontSize: 10)),
        ),
      const SizedBox(width: 8),
      Icon(Icons.chevron_right),
    ],
  ),
  onTap: () => _checkAppUpdate(context), // 新增方法
),

// 2. 版本检查逻辑
Future<void> _checkAppUpdate(BuildContext context) async {
  final currentVersion = _appVersion;
  final remoteVersion = await AppUpdateService.instance.checkForUpdate();
  
  if (remoteVersion == null) {
    _showUpdateDialog(context, '检查更新失败', '无法获取最新版本信息', null);
    return;
  }
  
  if (remoteVersion.tagName == currentVersion) {
    // 已是最新版本，清除跳过状态
    await AppUpdateService.instance.clearSkippedVersion();
    _showUpdateDialog(context, '已是最新版本', '当前版本: $currentVersion', null);
    return;
  }
  
  // 发现新版本，弹窗询问
  final shouldUpdate = await showDialog<bool>(
    context: context,
    builder: (ctx) => AlertDialog(
      title: const Text('发现新版本'),
      content: Text('当前版本: $currentVersion\n最新版本: ${remoteVersion.tagName}\n\n是否下载并更新？'),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(ctx, false), // 跳过
          child: const Text('暂不更新'),
        ),
        FilledButton(
          onPressed: () => Navigator.pop(ctx, true), // 更新
          child: const Text('更新'),
        ),
      ],
    ),
  );
  
  if (shouldUpdate == false) {
    // 用户选择跳过，保存跳过版本号，显示 new 标签
    await AppUpdateService.instance.skipVersion(remoteVersion.tagName);
    setState(() => _hasNewVersion = true);
  }
}
```
