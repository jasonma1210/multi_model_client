# Tesseract OCR Language Data

This directory should contain Tesseract language data files (.traineddata).

For Chinese (Simplified), download:
- chi_sim.traineddata (Simplified Chinese)
- chi_tra.traineddata (Traditional Chinese)
- eng.traineddata (English)

Download from: https://github.com/tesseract-ocr/tessdata

Place the .traineddata files in this directory.
